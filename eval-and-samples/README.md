# 评测与示例语料（eval-and-samples）

本目录为灵犀智能客服系统的 **W1 启动前置语料**，与 `规划书-智能客服系统.md`、`后端规划-智能客服系统.md`、`前端规划-智能客服系统.md` 配套使用。

## 目录结构
```
eval-and-samples/
├─ 评测问题库.md          # 80 条评测问题（W4 扩至 100 并冻结 ground-truth）
├─ README.md              # 本说明
├─ kb/                    # 示例知识库文档（W3 导入测试夹具）
│  ├─ 退换货政策.md
│  ├─ 运费与配送说明.md
│  ├─ 发货与时效.md
│  ├─ 会员权益.md
│  ├─ 发票政策.md
│  ├─ 支付与退款.txt
│  ├─ 商品保修条款.txt
│  ├─ 隐私政策.md
│  ├─ 账号与安全.md
│  └─ 常见问题FAQ.md
└─ kb-pdf/                # 真实 PDF 夹具（验 W3 的 PDF 解析路径，修 AegisDesk 坑）
   ├─ 退换货政策.pdf
   ├─ 商品保修条款.pdf
   └─ 隐私政策.pdf
```

## 用法
1. **W3 知识库导入**：将 `kb/` 与 `kb-pdf/` 全部文档上传到测试知识库。验证点：
   - `.txt/.md/.pdf` 三种格式均可解析；
   - sha256 去重生效（重复上传应跳过）；
   - PDF 能正确抽取文本（对照 AegisDesk 的 `NotImplementedError` 坑）。
2. **W4 评测**：按 `评测问题库.md` 逐条提问，记录 faithfulness / recall@5 / 首字时延，并回填 ground-truth（标准答案 + 期望引用文档）。
3. **冻结**：W4 末计算 `评测问题库.md` 的 sha256 与评测输出一并存档，后续指标只升不降。

## 事实约定（供 ground-truth 参考）
- 七天无理由退货（商品完好）；定制/生鲜/贴身衣物不支持。
- 质量问题退货运费商家承担；无理由退货运费买家承担（包邮商品商家承担发货运费）。
- 退款质检后 1–3 工作日原路退回。
- 满 ¥99 包邮；偏远地区 ¥15；默认中通/圆通。
- 现货 48h 内发货；预售 7–15 天；节假日顺延。
- 会员消费成长制、无会员费；金卡 95 折；100 积分=¥1，抵现上限 50%。
- 支持电子普通票与增值税专票；电票 24h 发邮箱。
- 支付：微信/支付宝/银联；重复扣款 1–3 工作日原路退。
- 数码家电保修 12 个月；人为/进水/私拆不保；过保收材料费+¥30。
- 隐私加密存储、不出售；注销 7 天生效。
- 【行业通用规则】加急 ¥10/单（16:00 前付款当日发，偏远/预售不支持）；改地址限付款后 24h 且未发货前；物流异常=72h 无更新或超期 3 天，丢件补发或全额退（含运费）；优惠券全额退原路回券、部分退不退券；价保 7 天（不含秒杀/券后价）。

## 📌 行业通用政策说明
`kb/` 中的以下 5 条政策为 **按电商行业惯例拟定的标准条款**，由用户确认"按行业规则即可"后作为工作基线（用户暂无可参考资料，按行业通用规则代填）：
- 加急发货 → `运费与配送说明.md` 第六节
- 修改收货地址 → `发货与时效.md` 第六节
- 物流异常处理 → `发货与时效.md` 第七节
- 优惠券退款 → `支付与退款.txt` 第六节
- 价保 → `常见问题FAQ.md` 新增"价保"节

每条行业通用条款在文档内已用 `> 📌 行业通用规则…` 标注，已作为本项目工作基线。若贵店实际业务与行业惯例不同，再按需微调即可，无需强制替换。基于这些条款的评测（Q046/Q050/Q051/Q062/Q076/Q080）口径有效。剩余 9 条诚实性评测题（Q042/Q049/Q055/Q060/Q061/Q067/Q069/Q071/Q074）仍为 KB 未覆盖，W4 单独记拒答正确率。
