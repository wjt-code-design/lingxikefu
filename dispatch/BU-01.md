## 0. 项目背景（必读，子 agent 无记忆）

本项目「灵犀 / Lingxi」是一套**面向企业的 RAG 智能客服系统**，参考蓝本为开源项目 aegisdesk-ai（FastAPI + LangGraph + Qdrant + React/AntD）。本单元只做 **MVP 脚手架（W1）**，目标是把后端可运行骨架 + 基础设施 + 工程纪律（测试/CI）从 day1 搭起来，为后续 BU-02~BU-09 提供基座。

**已锁定决策（ADR-1~5，不可改）：**
- 后端框架 **FastAPI**；编排 **LangGraph**；关系库 **PostgreSQL 16**；向量库 **Qdrant**；模型网关 **LiteLLM → 阿里云百炼**（用户供 Key）。
- 单租户 MVP：**全表必须含 `tenant_id` 字段**，MVP 固定单值（如 `"default"`），Phase3 才启用多租户行级过滤。
- MVP 仅 Web 渠道（HTTP+SSE）。Phase2 自建轻量工单。
- 密钥/endpoint **禁止硬编码或提交仓库**：百炼 Key 经 LiteLLM 网关 env/KMS 注入；`.env.example` 只放占位。

**红线（来自规划书⑨，验收会卡）：**
- 配置必须**单一 env 真源 + 启动校验**（`settings.validate()` 在 main 启动时调用），禁止出现 aegisdesk-ai 那种默认值三处自相矛盾的坑。
- 知识来源唯一真源 = 数据库 `message_sources`（本单元不实现，但表结构预留）。
- day1 必须有 **CI + 单测基线**。
- 禁止提交真实密钥 / 真实 endpoint（CI 需配 gitleaks 或等价 secret 扫描）。

## 2. 关键实现要求

### 2.1 config.py（重点）
- 用 `pydantic-settings` 的 `BaseSettings`，`env_file=".env"`，`env_prefix` 可选。
- 字段：`POSTGRES_HOST/PORT/USER/PASSWORD/DB`、`REDIS_URL`、`QDRANT_URL`、`QDRANT_API_KEY?`、`JWT_SECRET`、`ACCESS_TOKEN_EXPIRE_MINUTES=15`、`REFRESH_TOKEN_EXPIRE_DAYS=7`、`TENANT_DEFAULT="default"`、`LITELLM_MASTER_KEY`、`CORS_ORIGINS`（list）。
- `validate()` 方法：检查 `JWT_SECRET` 非占位、必填数据库 URL 存在、端口为 int；**不一致/缺失即抛 `ValueError`**，main 启动时调用，fail-closed。
- 必须出现一处**显式单测**证明：把 `JWT_SECRET` 设为 `__CHANGE_ME__` 时 `validate()` 抛错（防 aegisdesk-ai 占位泄漏）。

### 2.2 models（全表 tenant_id）
按《后端规划》§4.1 建模型：`users / sessions / messages / message_sources / knowledge_bases / documents / chunks / feedback / quotas / tickets*(预留) / chunk_context*(预留)`。每个模型第一个非 id 列即 `tenant_id: Mapped[str]`，默认 `settings.TENANT_DEFAULT`，建索引。

### 2.3 main.py
- `app = FastAPI(title="Lingxi Customer Service API", version="0.2")`。
- 启动时调用 `settings.validate()`（fail-closed）。
- `@app.get("/health")` 返回 `{"status":"ok","tenant": settings.TENANT_DEFAULT}`。
- CORS 中间件用 `settings.CORS_ORIGINS`。
- 挂载各 api router（本单元可为空 `APIRouter()`，但路由分组文件要存在，后续单元填充）。
- 可选：请求 ID 中间件（生成 `request_id`，用于错误模型）。

### 2.4 依赖/隔离
- 本单元**不依赖**任何业务模块。但 `app/` 目录结构要为 BU-02~BU-09 预留（见§1 目录清单）。
- 不连真实 PG/Qdrant/Redis 也能 import 与跑 `/health` 单测（用 `TestClient`，不触发真实连接）。
