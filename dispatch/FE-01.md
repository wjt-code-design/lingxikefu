## 0. 项目背景（必读，子 agent 无记忆）

本项目「灵犀 / Lingxi」是一套**面向企业的 RAG 智能客服系统**前端（React 19 + TS + AntD5）。本单元只做 **MVP 前端脚手架（W1）**，把可运行骨架 + 路由 + 状态 + 主题 + 契约类型 + 测试基建搭起来，为后续 FE-02~FE-05 提供基座。

**已锁定决策（不可改）：**
- 框架 **React 19 + TypeScript**；构建 **Vite 5**；UI **Ant Design 5**；数据请求 **Axios + React Query**；全局状态 **Zustand**；SSE 用 `fetch + ReadableStream`（原生 EventSource 不支持 POST+body）。
- 仅 Web 渠道。MVP 三块界面：① 可嵌入**对话挂件**（`/widget` iframe 嵌入 + `/chat` 站内完整页，共用 `ChatWidget`）② **客服后台** ③ **管理后台**。
- 主题必须支持 **light / dark / system** 三态切换，瞬时无闪烁（`<html data-theme>` + AntD `theme.darkAlgorithm` 同步）。
- 契约优先：类型定义从后端契约**派生**，禁止前端自定义字段名漂移。

**红线：**
- `contracts/api.ts` 字段/枚举必须与后端 §3 完全一致（见 `contracts/api.ts` 已给出真源，直接拷贝到 `frontend/src/contracts/api.ts`）。
- `tsc --noEmit` 必须全绿（CI）。
- 不提交真实密钥；`.env.example` 只放 `VITE_API_BASE=/api/v1` 之类占位。

## 2. 关键实现要求

### 2.1 设计 Token（写入 `styles/tokens.css`，语义变量名固定）
照《前端规划》§2.1 落地 CSS 变量（light + `[data-theme="dark"]`）：
```
--color-brand:#2F6BFF; --color-brand-soft:#E8F0FF; --color-accent:#14C8A0;
--color-surface:#FFFFFF; --color-ink:#1A2233; --color-muted:#6B7689;
--color-danger:#F5455C; --radius-md:12px; --shadow-card:0 2px 12px rgba(26,34,51,.06);
```
dark 下覆盖 `--color-surface:#1B1F2A; --color-ink:#E8ECF2; --color-muted:#9AA4B5; --color-brand-soft:#1E2A45; --shadow-card:0 2px 12px rgba(0,0,0,.35)`。
`themeStore` 切 `<html data-theme>` + AntD `theme.darkAlgorithm` 同步，瞬时无闪烁。

### 2.2 路由表（含守卫，见《前端规划》§1.1）
`/login`,`/register`（匿名）/`/widget`（匿名/普通用户）/`/chat`（access）/`/admin/knowledge`,`/admin/users`,`/admin/stats`（admin）/`/agent/sessions`,`/agent/tickets`（agent/admin，Phase2）。用 react-router v6 + 一个 `RequireAuth` 守卫组件（读 `authStore`；未登录跳 `/login`，非 admin 访问 `/admin/*` 跳 `/login` 或 403 页）。本单元页为已壳，但路由 + 守卫必须可切换、可重定向。

### 2.3 契约优先
- `frontend/src/contracts/api.ts` 必须 **逐字段等于** 根 `contracts/api.ts`。CI 用 `tsc --noEmit` 保证类型一致；本单元额外点：所有 api client 函数签名用 `contracts/api.ts` 的类型，禁止在组件里手写请求体字段。
