## 批次 H：遗留债清偿（4 任务）

### H1 _ORDER_RE Unicode 边界修复【最高优先】
- 修复：query_rewrite.py:64 `\b` → `(?<![A-Za-z0-9])...(?![0-9A-Za-z])`；**只动 _ORDER_RE**。
- **行为变化声明（必须验证+提交注明）**：订单号槽位变宽 → 更多会话命中订单工具短路；回归验证订单工具查不到单号时的回落路径。
- 证据源：手工复现清单（'订单SO2026080118到哪了' 现全 miss → 修后命中）；既有带空格用例=对照锚；负例=长 ASCII 标识符中段不误提。禁开 IGNORECASE。~1h。

### H2 quota 锁内 DB IO 上界
- database.py engine 补 `connect_args={"connect_timeout": 5}`（照 main.py:139 先例）。
- daily_limit 双检精确化：**锁外无锁读缓存快照（命中即返）→ miss 进锁 → 锁内 double-check → 读库 → 发布**。
- 证据源：main.py:139 先例 + psycopg3 connect_timeout 语义；DB 停摆模拟超时回退单测（实测）；陈旧值 ≤1 TTL（论证，标注）。~2h。

### H3 语义缓存极性极大类归并
- 修探索方案 b 缺陷：裸"不"⊂"不能"致类集合永不等——归并只保留极大类（匹配"不能"则"不"不计入）→"无法退"与"不能退"类集合同为 {"不能"} → 命中。
- 边界：不动 payload/词表本体；既有断言（能退/不能退仍 conflict）不得翻转；注释同步不变量。证据源：同义常识 + 既有断言对照。~1.5h。

### H4 观测性打包
- quick_answers：Redis 可达但 key 缺失且模块态有值 → info 日志一次（防静默放行窗口）。
- intent-shadow stats 加 min_total/remaining（INTENT_SHADOW_MIN_TOTAL 进 config；additive 前端暂不消费，标注）。
- 收尾：全量 + ruff + **契约检查**（H4 动 schema）。~1h。

## 批次 G：门禁 v2（3 任务）

**核心设计**：staged 通道 = **chunk 级 `visible` payload 过滤**（弃双 collection：全局单值需穿透 4 调用链+整库重嵌入；弃回滚式：不满足阻断生效）。三导入入口收敛于 import_document 纯函数，门禁一处插入全覆盖。

### G1 visible staged 通道 + 部署顺序【修自审重要-1/5】
- `import_document(..., visible: bool = True)` 参数化：默认 True（smoke/单文档直传/评测路径零改动=豁免），batch 流程显式 False。
- payload 写入加 visible（vector_service upsert 一处）；检索 Filter 加 visible=True（retrieval_service.py:98-103 一处，4 调用方自动生效）。
- **部署顺序强制**：回填脚本先行（存量 point set visible=true）→ **对账断言**（visible=true 计数 == indexed chunks 总数，不对账不提交）→ 再上 filter 代码（否则存量无字段全不可见=检索全挂）。
- 证据源：既有检索测试扩展（实测）；回填对账=手算；**全量评测实测存档**（动了检索 filter=评测路径变更）。

### G2 发布流编排【补齐三设计空缺】
- batch 发起方：knowledge.py 上传端点加**可选** batch_id；管理端"发布"动作（选 pending 批次→触发快检→PASS 发布）；不带 batch_id 直传保持直通（渐进采用）。
- 批次状态机：pending→evaluating→released/rolled_back/failed（failed 占比>0 即终态人工重提，防卡死）。
- **评测分级**：batch 完成触发抽样快检（确定性步长 20 题，~20min）；全量评测仍人工/定期——避免每次导入烧 1h 全量。
- 判定复用 v1 `_gate_passed`；FAIL 保持 visible=false + 坐席通知告警；回滚接口 = set_payload 翻转（分钟级）。
- 证据源：gate 阈值=既有红测；批次端到端=集成测试（FAIL 桩断言不可见→PASS 桩断言翻转）。

### G3 观测与文档
- gate 端点加 staged 批次视图（batch_id/文档数/评测态/可见态）；方案文档补"门禁 v2 设计与豁免清单"章节。
- 收尾：全量 + ruff + 契约检查 + **全量评测实测存档**（动了检索 filter=评测路径变更，强制全量）+ push CI。
