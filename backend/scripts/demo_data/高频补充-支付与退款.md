# 支付与退款说明（演示）

> 以下为客服系统演示用的支付与退款政策数据，非真实契约。用于演示"退款多久到账""退回哪个渠道"等售后场景。

## 支持的支付方式
支持微信支付、支付宝、银联云闪付三种支付方式，暂不支持货到付款与外币支付。

## 退款到账时间
所有退款均按"原路退回"原则处理：微信支付退回到微信零钱，支付宝退回到支付宝余额，银行卡退回到原卡。
退款到账时间受支付机构与银行处理时效影响，常规 1-3 个工作日到账；超过 3 个工作日仍未到账，可联系在线客服并提供交易流水号核实处理。

## 支付失败 / 重复扣款
- 已扣款但订单未生成：款项通常 1-3 个工作日内自动原路退回，无需手动申请；
- 因网络抖动重复扣款：系统对账后自动退回多扣部分，如 3 个工作日未到账，请提供两笔交易流水号协助核实。

## 优惠券退款
- 全额退款（未发货取消 / 质量问题 / 7 天无理由）且未使用运费券：优惠券原路退回卡券包，有效期按"原有效期剩余天数"与"退回后 30 天"取较长者；
- 部分退款或已使用的优惠券：不退回。
