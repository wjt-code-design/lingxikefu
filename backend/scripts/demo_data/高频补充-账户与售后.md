# 账户与售后高频补充（常见问答）

以下为客服系统用于补齐高频账户/售后问题的资料，非真实订单数据。

## 换货怎么做
- 订单签收后，商品未激活、未拆封（或质量问题已留证）可申请换货。
- 路径：我的订单 → 申请售后 → 选择"换货"→ 按系统引导填写换货原因。
- 申请通过后，按提示寄回旧品，质检通过后发出新品（换货运费规则与退货一致，质量问题免运费）。
- 换货进度可在"我的订单-售后"实时查看。

## 系统怎么升级
- 方法：设置 → 关于本机 → 系统更新 → 检查更新，选择在线升级（OTA）。
- 星河会通过站内信通知重大版本更新；升级前请备份数据并保持电量充足。

## 修改登录密码
- 路径：个人中心 → 设置 → 账号与安全 → 修改密码。
- 需验证当前密码后设置新密码；忘记原密码可走"找回密码"（验证绑定手机/邮箱）。
- 新密码需同时包含字母和数字，长度不少于 8 位。

## 绑定 / 解绑手机号
- 绑定新手机号：账号与安全 → 手机号 → 更换，通过原手机号验证码验证后更换。
- 解绑：先绑定新的可接收验证码的手机号，再解绑旧号（保证账号随时可找回）。
- 换机/换号前请先完成换绑，避免无法登录。

## 短信验证码收不到怎么办
- 先检查：是否被拦截（短信防护/骚扰拦截）、是否信号弱（飞行模式重开）、是否填错手机号。
- 多次收不到可改为"语音验证码"或邮箱验证码。
- 仍无法收到可联系人工客服，核实身份后代为处理。客服不会通过对话索要验证码。
